# ScrapeCreators method

> PLACEHOLDER TO FOLD. ScrapeCreators publishes an official skill; fold it
> in here (keeping this frontmatter's name). Until then, the essentials:

- `creator_profile(platform, handle)` first — confirms the handle resolves
  and gives the denominator (followers) every engagement read needs.
- `creator_posts(platform, handle, count)` — recent posts with counts.
  Engagement RATE (interactions / followers) is the comparable number;
  raw likes are not comparable across creators.
- Public data only. If a profile is private or missing, report that as the
  finding — do not try alternate routes.
- Platforms name fields differently; normalise before comparing across
  platforms, and say which platform each number came from.
